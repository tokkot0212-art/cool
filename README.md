# 🧊 冷蔵庫コンシェルジュ

**あなたの食生活を支えます**

冷蔵庫の扉に貼ったタブレットやスマホで使う、自分用の食材管理アプリです。
インストール不要。ブラウザで開くだけで動きます。

## できること

| タブ | 内容 |
|---|---|
| 🧊 冷蔵庫 | 場所別（上段・中段・下段・チルド・ドアポケット・野菜室・冷凍）の地図で中身を表示。期限が近い食材をコンシェルジュが教えてくれる |
| 🧂 常温・調味料 | 冷蔵しない食材（玉ねぎ・米・缶詰など）と調味料を別に管理 |
| ➕ 登録 | 食材・調味料を選んで、残量（10〜1、1/2、0）、購入日（今日・昨日をタップ）、冷蔵/冷凍/常温、場所、購入方法を入力 |
| 🍳 レシピ | 選んだ食材で作れる料理（1つの食材だけでもOK）。50品の手持ちレシピ＋Geminiによる提案。「1食材を世界の食べ方で」も |
| ⭐ 記録 | 作った料理を星で評価。実際に使った材料・調味料の量を学習し、次回のレシピの分量と並び順に反映 |
| 🎁 おまけ | 家族のリクエスト（仮の予定日つき）、便利な調理器具・食材・調味料の情報（10件中1件は過去1か月のトレンド） |

- 賞味期限は、食材ごとの一般的な目安（冷蔵・冷凍・常温）から自動で決まります。手動で直すこともできます。
- 冷蔵庫の場所は「⚙️ 設定」で自由に名前を変えたり、増やしたりできます（最初は仮でOK）。

## 使い方

1. GitHub Pages のURLをタブレットで開く
2. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように全画面で使えます
3. 「登録」タブで、今ある食材と調味料を選んで登録

### Gemini（AI）を使う場合（任意）

1. [Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを作成
2. アプリの「⚙️ 設定」→「APIキー」に貼り付けて保存

APIキーやデータは、**その端末のブラウザの中だけ**に保存されます（GitHubには送られません）。
APIキーなしでも、在庫管理・手持ちレシピ・評価・リクエストはすべて使えます。

## データについて

- データは端末のブラウザ（localStorage）に保存されます。ブラウザのデータを消すと消えます。
- 「設定」→「書き出し（JSON）」でバックアップ、「読み込み」で復元できます（APIキーは書き出しに含まれません）。

## ファイル構成

```
index.html   画面の枠
style.css    見た目
app.js       アプリ本体
data.js      食材・調味料・期限の目安・レシピのデータ（ここを編集すればレシピを増やせます）
sw.js        オフラインでも開けるようにするキャッシュ
```

※ 賞味期限は一般的な目安です。実際はパッケージの表示を優先してください。
